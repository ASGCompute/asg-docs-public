## Status Legend

| Icon | Meaning |
|:-----|:--------|
| ✅ Available | Active in production, ready to use |
| 🔧 Upgrading | Temporarily unavailable, being upgraded |
| 🔜 Coming Soon | On the roadmap, not yet deployed |

## Live Discovery

You can always check the latest tool status via the capabilities endpoint:

```bash
curl -s https://agent.asgcompute.com/mcp/capabilities | jq '.tools[] | {name, status}'
```
