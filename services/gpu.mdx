# ASG GPU

<Warning>
**Coming Soon** — GPU provisioning is on the roadmap. The tools described below are planned but not yet active. See [Roadmap](/resources/roadmap) for timeline.
</Warning>

Rent dedicated GPU instances on-demand with per-second billing.

## Planned Capabilities

- **H100, A100, RTX 4090** — Premium GPUs
- **Per-second billing** — No hourly minimums
- **Instant provisioning** — Target <30 seconds
- **SSH access** — Full control of your pod

## Planned Tools

| Tool | Description |
|:-----|:------------|
| `gpu_provision` | Provision a GPU pod |
| `gpu_heartbeat` | Extend a lease |
| `gpu_terminate` | Terminate a pod |

## Currently Active Tools

While GPU is not yet available, you can use these tools today:

- **`inference_chat`** — AI completions with 100+ models
- **`sandbox_execute`** — Isolated code execution
- **`optify_vram_estimate`** — Estimate VRAM requirements for models
