# Changelog

All notable changes to ASG Agent Cloud.

## v5.1.0 — 2026-02-01

### Added
- 🚀 Public Beta launch
- 💳 Gasless USDC payments on Solana
- 🤖 MCP protocol support
- 🎯 Four core services: Inference, Serverless, GPU, Sandbox
- 📊 Receipt system with automatic refunds

### Services
- **Inference:** 100+ models via `asg-fast`, `asg-balanced`, `asg-powerful`
- **Serverless:** Python 3.11 and Node 18 runtimes
- **GPU:** RTX 4090, A100, H100 pods
- **Sandbox:** Isolated code execution

## v5.0.0 — 2026-01-15 (Internal)

### Added
- Core billing infrastructure
- Control plane with budget enforcement
- Gateway with rate limiting
- White-label compliance
